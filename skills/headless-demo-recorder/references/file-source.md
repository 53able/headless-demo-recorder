# file ソース（既存の動画を編集する）

録画済みの動画（QuickTime、OBS、以前の `capture.mp4` など）に、ズーム・マーカー・字幕を付けて書き出す。ブラウザも対象アプリも起動しない。`run` を使ってよく、その capture 段階は ffmpeg による変換だけを行う（書き出しには `openscreen` を使うので、Codex ではサンドボックス外での実行が要る）。

- `source`: `{ "type": "file", "path": "<動画>", "events": "<操作ログ>" }`。`events` は省略できる（その場合、ズーム・マーカー・字幕は付かない）。パスは実行時のカレントディレクトリからの相対で解決される。
- 操作ログは `ActionEvent` の配列（`scripts/types.ts`）。座標はすべて動画のフレームに対する 0〜1 の比率で表す。
  - `tMs`（必須）: 動画上の時刻（ミリ秒）
  - `kind`（必須）: `click` / `type` / `press` / `scroll` / `navigate` / `wait` / `mark`
  - `point`: 操作した点 `{cx, cy}`（`{x, y}` ではない。ピクセル値ではなく比率）。`point` を持つ `click` / `type` がズームの中心になり、その要素にマーカーが重なる（マーカーの詳細は SKILL.md の「マーカーとカーソル」）
  - `rect`: 対象要素の矩形 `{x, y, w, h}`。マーカーの位置と大きさ、`redact: true` のときのぼかし領域に使う。`rect` が無い `click` / `type` は `point` を中心に固定の大きさでマーカーを描き、`rect` の無い `redact` は効かない
  - `caption`（字幕の文字列）、`zoom`（false でそのイベントをズームしない）、`redact`
- `check` は操作ログの形式も検証する。ログの中身（ラベルや座標）が動画に映っているものと合っているかは検証しないので、SKILL.md の作業ループ5の目視確認で確かめる。

書き出した動画は OpenScreen が余白と背景を付けるため、解像度とフレームレートが入力と一致しない（例: 1280x720・30fps の入力から 1784x1080・60fps の出力）。サイズが重要なら `ffprobe` で出力を確かめる。
